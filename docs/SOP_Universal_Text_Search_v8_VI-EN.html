1. Mục đíchPurpose

Hướng dẫn người dùng cuối tìm nhanh nội dung chữ bên trong tài liệu (Excel, Word, PDF, HTML, văn bản thuần…) bằng Universal Text Search v8, không cần mở từng tệp.

Guide end users to quickly find text inside documents (Excel, Word, PDF, HTML, plain text…) with Universal Text Search v8, without opening each file.

2. Phạm vi áp dụngScope

Áp dụng cho mọi người dùng Windows 10/11 sử dụng tệp Universal_Text_Search_v8.exe.

Applies to all Windows 10/11 users running Universal_Text_Search_v8.exe.

Tìm trong thư mục trên ổ cục bộ và ổ mạng.

Searches folders on local and network drives.

Phần mềm chỉ đọc tệp: không sửa, không xoá, không gửi dữ liệu ra ngoài.

The software only reads files: it never edits, deletes or uploads them.

Không áp dụng cho PDF dạng ảnh quét (không có OCR) và tệp PowerPoint.

Not applicable to scanned-image PDFs (no OCR) and PowerPoint files.

4. Yêu cầu hệ thốngRequirements

Windows 10 hoặc 11 (64-bit). Không cần cài đặt, không cần Python.

Windows 10 or 11 (64-bit). No installation and no Python required.

Tệp Universal_Text_Search_v8.exe (khoảng 23 MB) đặt ở thư mục bất kỳ có quyền chạy.

The Universal_Text_Search_v8.exe file (about 23 MB) placed in any folder you can run from.

Quyền đọc các thư mục cần tìm; quyền ghi vào thư mục AppData của bạn (để lưu chỉ mục).

Read access to the folders to search; write access to your AppData folder (to store the index).

6. Quy trình thực hiệnProcedure

6.1 Khởi độngStart the application

  1. Nhấp đúp Universal_Text_Search_v8.exe.

    Double-click Universal_Text_Search_v8.exe.

  2. Chờ vài giây ở lần mở (ứng dụng tự giải nén). Nếu Windows SmartScreen hiện cảnh báo và tệp đến từ nguồn tin cậy: chọn More info → Run anyway.

    Wait a few seconds on launch (the app unpacks itself). If Windows SmartScreen warns and the file comes from a trusted source: choose More info → Run anyway.

  3. Cửa sổ “Universal Text Search v8 — PharmApp” mở ở tab Search v8.

    The “Universal Text Search v8 — PharmApp” window opens on the Search v8 tab.

6.2 Thêm thư mục và lập chỉ mục lần đầuAdd folders and build the index (first time)

  1. Bấm Add Folder (Ctrl+O), chọn thư mục. Đường dẫn xuất hiện ở ô (7). Lặp lại cho nhiều thư mục, hoặc dùng Paste Paths để dán nhiều đường dẫn.

    Click Add Folder (Ctrl+O) and pick a folder. The path appears in box (7). Repeat for more folders, or use Paste Paths to paste several paths.

  2. Giữ nguyên dấu tick Use Index (FTS) (5) và tick các loại tệp cần tìm (6).

    Keep Use Index (FTS) (5) ticked and tick the file types you need (6).

  3. Bấm Update Index (Ctrl+U). Thanh trạng thái hiện “Indexing […]”.

    Click Update Index (Ctrl+U). The status bar shows “Indexing […]”.

  4. Đợi dòng “Index updated. Scanned X, changed Y.” Có thể nhấn Esc để huỷ.

    Wait for “Index updated. Scanned X, changed Y.” Press Esc to cancel.

Mẹo / Tip

Chỉ cần lập chỉ mục một lần cho mỗi thư mục. Các lần sau chỉ tệp thay đổi được đọc lại.

Index each folder once. Later runs only re-read files that changed.

6.3 Tìm kiếm bằng chỉ mục (nhanh)Search with the index (fast)

  1. Gõ từ khoá vào ô (1). Có thể gõ không dấu: “thuoc nho mat” vẫn tìm được “Thuốc nhỏ mắt”.

    Type the keyword in (1). Accents are optional: “thuoc nho mat” still finds “Thuốc nhỏ mắt”.

  2. (Tuỳ chọn) đặt From/To (4) theo dạng YYYY-MM-DD.

    (Optional) set From/To (4) as YYYY-MM-DD.

  3. Nhấn Enter hoặc bấm Search (3).

    Press Enter or click Search (3).

  4. Thanh trạng thái hiện “FTS: n result(s)”. Kết quả mới nhất ở trên, tối đa 3000 dòng.

    The status bar shows “FTS: n result(s)”. Newest results first, up to 3000 rows.

  5. Muốn gọn hơn: thêm từ khoá, bỏ bớt loại tệp, thu hẹp ngày hoặc thư mục.

    To narrow down: add keywords, untick file types, or limit dates/folders.

6.4 Cú pháp tìm nâng cao (khi dùng chỉ mục)Advanced syntax (when using the index)

GõTypeKết quảResult
red ponceauTệp chứa cả hai từ, ở vị trí bất kỳ.Files containing both words anywhere.
"red ponceau"Đúng cụm từ, đúng thứ tự.The exact phrase in that order.
ponceau OR carmoisineMột trong hai từ (viết HOA OR).Either word (OR in capitals).
ponceau NOT azoCó “ponceau” nhưng không có “azo” (viết HOA NOT).Has “ponceau” but not “azo” (NOT in capitals).
ponce*Mọi từ bắt đầu bằng “ponce”.Any word starting with “ponce”.
Lưu ý / Note

Dấu gạch ngang, dấu cộng hoặc ngoặc kép là ký tự cú pháp. Muốn tìm đúng “4-R” hãy đặt trong ngoặc kép: "4-R".

A hyphen, plus sign or quote is syntax. To find “4-R” literally, put it in quotes: "4-R".

6.5 Quét trực tiếp (không dùng chỉ mục)Live scan (without the index)

  1. Bỏ dấu tick Use Index (FTS) (5).

    Untick Use Index (FTS) (5).

  2. Chọn Case-insensitive nếu không phân biệt hoa/thường; đặt ngày và loại tệp.

    Tick Case-insensitive to ignore upper/lower case; set dates and file types.

  3. Nhập từ khoá, nhấn Enter. Thanh trạng thái hiện “Scanning […]”, kết quả xuất hiện dần; kết thúc bằng “Done. Scanned N file(s). Matches: M”.

    Enter the keyword and press Enter. The status bar shows “Scanning […]”, results appear gradually and finish with “Done. Scanned N file(s). Matches: M”.

  4. Nhấn Esc để dừng giữa chừng.

    Press Esc to stop at any time.

Mẹo / Tip

Quét trực tiếp tìm đúng chuỗi ký tự bạn gõ (không bỏ dấu tiếng Việt, không dùng AND/OR/NOT) và hiển thị thêm cột Created/Accessed.

Live scan matches the exact characters you type (Vietnamese accents matter, no AND/OR/NOT) and also fills the Created/Accessed columns.

6.6 Làm việc với kết quảWork with the results

  1. Bấm tiêu đề cột để sắp xếp (mũi tên ▲/▼ cho biết chiều).

    Click a column header to sort (the ▲/▼ arrow shows the direction).

  2. Chọn dòng: bấm; nhiều dòng: giữ Ctrl hoặc Shift; tất cả: Ctrl+A.

    Select a row by clicking; several rows with Ctrl or Shift; all with Ctrl+A.

  3. Open Selected (Ctrl+E), nhấp đúp hoặc Enter: mở tệp bằng chương trình mặc định.

    Open Selected (Ctrl+E), double-click or Enter: opens the file in its default program.

  4. Reveal (Ctrl+Shift+E): mở thư mục chứa tệp và chọn sẵn tệp.

    Reveal (Ctrl+Shift+E): opens the containing folder with the file selected.

  5. Copy Paths (Ctrl+C): chép đường dẫn các dòng đã chọn (hoặc tất cả nếu chưa chọn) vào clipboard.

    Copy Paths (Ctrl+C): copies the selected paths (or all if none selected) to the clipboard.

  6. Chuột phải trên bảng để mở menu nhanh. Clear Results (Ctrl+L) để xoá bảng.

    Right-click the table for the quick menu. Clear Results (Ctrl+L) empties the table.

6.7 Đổi giao diệnChange the appearance

  1. Chọn trong ô Appearance (11) hoặc menu View → Appearance.

    Pick from the Appearance box (11) or the View → Appearance menu.

  2. Có 5 lựa chọn: System (theo Windows), Light, Dark, Luxury Warm, Modern Blue-Gray. Giao diện đổi ngay, không cần khởi động lại và được ghi nhớ cho lần sau.

    Five options: System (follows Windows), Light, Dark, Luxury Warm, Modern Blue-Gray. The change is immediate, needs no restart and is remembered.

6.8 Giữ chỉ mục luôn cập nhậtKeep the index up to date

  1. Khi Use Index bật, ứng dụng tự theo dõi các thư mục (thanh trạng thái “Watch: active.”): tệp mới, sửa hoặc xoá được cập nhật tự động trong lúc ứng dụng đang mở.

    With Use Index on, the app watches your folders (status “Watch: active.”): new, edited or deleted files are updated automatically while the app is open.

  2. Tệp thay đổi khi ứng dụng đóng, hoặc trên ổ mạng không báo thay đổi: bấm Update Index (Ctrl+U).

    For files changed while the app was closed, or on network drives that do not report changes: click Update Index (Ctrl+U).
